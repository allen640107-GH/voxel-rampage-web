# 方塊巨獸大暴走 Voxel Rampage　v1.0.0

操控巨獸在**體素（Minecraft 式方塊）城市**裡大鬧：踩踏、甩尾、衝撞、吼叫衝擊波，把大樓、汽車、路燈打成滿天飛的方塊！
大樓的支撐是用**方塊連通性**判斷的：打斷支撐後，懸空的上半部會整塊掉下來；把底部打掉，整棟樓會一邊下沉一邊崩塌，還可能砸壞旁邊的建築。

**立即遊玩：** https://allen640107-gh.github.io/voxel-rampage-web/

![封面](img/cover.jpg)

## 玩法
- 每關 **90 秒**，破壞率達到 **30% / 55% / 80%** 分別拿到 1 / 2 / 3 顆星；1 顆星就算過關並解鎖下一個城市。破壞率達到 92% 會提早結束（城市全毀）。
- 連續破壞會累積**連擊**，分數倍率最高 ×5。整棟倒塌 +500、汽車 +200。
- **3 隻巨獸**
  - 暴龍・雷克斯：平衡型，甩尾範圍大
  - 巨猿・剛猛：速度型，移動快、捶地猛
  - 晶甲獸・鐵甲：重裝型，慢，但破壞範圍最大
- **3 個城市**：現代市中心（白天）→ 黃昏海港（貨櫃、起重機、貨輪）→ 霓虹夜城（夜晚霓虹）

## 操作
| | 手機／平板（觸控） | 電腦 |
|---|---|---|
| 移動 | 左下虛擬搖桿（左半邊任意處按下都可以） | WASD／方向鍵 |
| 轉視角 | 在畫面上拖曳 | Q／E，或滑鼠拖曳 |
| 踩踏 | 「踩踏」鍵（按住會連發） | J |
| 甩尾 | 「甩尾」鍵 | K |
| 衝撞 | 「衝撞」鍵 | L |
| 吼叫衝擊波 | 紫色「吼叫」鍵 | 空白鍵 |
| 暫停 | 左上 ❚❚ | Esc／P |

一邊用搖桿移動、一邊用另一根手指按攻擊鍵（多點觸控）。相機被大樓擋住時，擋住的部分會自動「挖空」，永遠看得到巨獸。

## 片頭與聲音
- 每次進遊戲自動播放片頭（靜音自動播放，瀏覽器規定）。**點一下畫面就開聲音**；右上角一直有大大的「**跳過動畫 ▶▶**」。
- 音訊移植「恐龍防線」v2.2.1 的修正：每次觸控／點擊／按鍵都會檢查並恢復 AudioContext 與音樂，切換分頁（visibilitychange）、從背景回來（pageshow / focus）會自動續播，並有 2 秒看門狗。

## 效能與畫質
- 城市是 96×56×96 的體素網格，切成 16³ 的分塊網格（面剔除＋頂點 AO），只重建被破壞的分塊。
- 碎塊使用 **InstancedMesh 物件池**（低／中／高 = 240 / 460 / 760 個上限），滿了就回收最舊的。煙塵也是物件池。
- 「自動」畫質依裝置記憶體、核心數與觸控判斷起始等級，遊戲中 FPS 持續低於 36 會自動降一級（降解析度、關陰影、減少碎塊與車流）。設定中可手動選高／中／低。
- 支援 Galaxy Z Fold 外螢幕（窄長）與展開（近正方形）全螢幕、iPhone 瀏海安全區域（safe-area）。

## 存檔
- 存在瀏覽器 localStorage（`voxelRampage.save`），**含版本號（目前 v2）與自動遷移**。
- 遷移前會把舊資料原封不動備份到 `voxelRampage.save.bak.v<舊版>`；讀不懂的存檔會先備份到 `voxelRampage.save.corrupt.<時間>`。**永不刪除存檔**。較新版本的存檔不會被降版覆蓋。
- 遊戲不會送出任何網路請求到第三方（沒有計數器、沒有分析、沒有需要金鑰的服務）。

## 在本機執行
需要用 HTTP 伺服器開（ES modules 不能用 file://）：
```bash
cd voxel-rampage-web
python3 -m http.server 8000
# 瀏覽器開 http://localhost:8000/
```
three.js 以本地檔案放在 `vendor/`（r187，MIT），不依賴 CDN。網址加 `?nointro` 可以跳過片頭直接到主選單。

## 測試
```bash
pip install playwright   # 使用系統 Chrome：/usr/bin/google-chrome
python3 tests/play.py http://localhost:8000/ pc OUTDIR full   # 完整：片頭、音樂恢復、選角、鍵盤、自動遊玩整整一關並通關
python3 tests/play.py http://localhost:8000/ iphone OUTDIR    # 尺寸：pc se iphone iphone_land foldcover foldopen
python3 tests/save_migration.py http://localhost:8000/        # 存檔遷移 v0/v1/壞檔/未來版本
```
測試在全新的瀏覽器設定檔中執行，只檢查 0 個 console 錯誤、所有請求都只到同一網站（不會增加任何計數）。

## 已知限制（v1.0.0）
- iPhone Safari 無法在開發環境實測（WebKit 無法在測試機上執行），觸控程式依標準 Pointer Events 撰寫並以 Chrome 行動模擬測試。
- 掉落的整塊結構不和其他建築做完整碰撞（落在屋頂上會砸出缺口後碎掉；落地則下沉崩解）。
